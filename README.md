# Парковочный навигатор (CV + AI)

Проект: система находит свободное парковочное место по камере
в реальном времени и ведёт к нему водителя. Пользователь вводит адрес
назначения, получает маршрут и конкретное свободное место рядом.

Ниже — структура репозитория и назначение каждой папки.

## Компоненты и поток данных

1. Водитель вводит адрес назначения на карте.
2. Дальше 700 м от цели — обычный маршрут, поиск мест не запускается.
3. В зоне 700 м фронтенд запрашивает у Go свободные места в радиусе 100 м
   от назначения.
4. Go выбирает ближайшее к цели место и 2–3 соседних по свежим статусам
   из PostgreSQL; если подходящих нет — отвечает «данных нет».
5. Камера в реальном времени → Python-сервис: YOLO11 + ByteTrack определяют,
   занято ли каждое место, и отправляют события в Go.
6. Go сохраняет историю, обновляет текущий статус и рассылает изменения
   по WebSocket.
7. Фронтенд строит маршрут через Яндекс Карты, подсвечивает место и обновляет
   его статус на ходу. Если место заняли — предлагает следующее, но не чаще
   раза в 20–30 с.
8. Если мест/камер нет — молча работает обычный маршрут до назначения.

## Стек

- **CV**: Python 3.11, OpenCV, Ultralytics YOLO11, ByteTrack, FastAPI
- **Backend**: Go 1.23, Gin 1.11, pgx v5, PostgreSQL 16, golang-migrate, JWT, WebSocket
- **Frontend**: React 19 + TypeScript + Vite, Яндекс Карты JS API (карта, геокодер,
  маршруты), TanStack Query, Zustand
- **Инфраструктура**: Docker Compose, Nginx

## Быстрый старт

```bash
cp .env.example .env   # при необходимости сгенерируйте секреты
make up                # postgres + миграции + backend
make seed              # демо-парковка: 8 мест и камера
curl localhost:8080/api/health
make psql              # psql внутри контейнера
```

Порты на хосте: backend `8080`, PostgreSQL `5432` (внутри контейнеров —
те же 8080 и 5432). Значения вынесены в `.env`.
