# cv (Python)

Сервис компьютерного зрения.

- `app/detection` — детекция автомобилей (YOLO).
- `app/tracking` — трекинг между кадрами (ByteTrack).
- `app/occupancy` — определение занятости мест по полигонам.
- `app/pipeline` — обработка загруженного видеофайла.
- `app/storage` — отправка результатов в Go-бэкенд.
- `models/` — веса моделей (не коммитятся).
- `notebooks/` — обучение и эксперименты.

Вход: видеофайл (mp4/avi) + конфиг парковки (полигоны мест).
Выход: события `spot_id`, `status`, `confidence`, `timestamp`, `snapshot`.
Загрузка идёт через веб-интерфейс → Go-бэкенд → этот сервис.
