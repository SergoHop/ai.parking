# frontend

Веб-интерфейс: карта парковок и live-статусы мест.

- `src/pages` — карта, страница парковки, статистика, админка.
- `src/features/parking-map` — карта, слой парковок, полигоны мест.
- `src/components` — общие UI-компоненты.
- `src/api` — REST-клиент и WebSocket.
- `src/store` — состояние приложения.

Стек: TypeScript + Vite. Карта — Яндекс Карты JS API (ключ в `.env`).
Фреймворк (React или Vue) ещё не выбран, поэтому структура нейтральная.
